# 🚀 Обновление Dropushko 2.3.2

---

### 🔧 Исправления и стабильность:

- 🛠️ **Исправление проблемы с пустым экраном сервисов (Critical BugFix):**
  - Устранена критическая ошибка `ReferenceError: setter is not defined` в `service-panel.js`, приводившая к сбою рендера списка служб при синхронизации числовых параметров с диапазоном (например, `min_cost` / `max_cost` в SteamGifts).
  - Инициализация каждого сервиса в `services.js` изолирована в блоках `try/catch` — сбой отдельной службы больше не блокирует отображение остальных сервисов.
  - Устранено состояние гонки при загрузке главного окна: сигнал `window-loaded` теперь отправляется после полной инициализации всех обработчиков.

---

### ✨ Новые возможности:

- 🔄 **Кнопка быстрого обновления сервисов:**
  - В шапку программы (в верхний блок действий) добавлена кнопка **«Обновить интерфейс сервисов»** с плавной анимацией.
  - Позволяет мгновенно обновить список и состояние всех служб без перезапуска программы, сохраняя выбранный сервис и открытую вкладку.

- 🔔 **Оповещение о новых версиях и предложение скачать:**
  - Добавлена автоматическая проверка свежих версий через GitHub Releases API.
  - При обнаружении новой версии в шапке появляется привлекательный анимированный значок и открывается модальное окно с описанием изменений (Release Notes) и кнопкой прямого перехода к скачиванию.
  - В раздел **«Настройки»** рядом с номером версии добавлена кнопка **«Проверить обновления»** с выводом текущего статуса.
