# 🛠️ Хотфикс Dropushko v2.3.1 (BugFix)

---

### 🔧 Исправления:

- 🛒 **Mannco.store — Исправление авторизации и сохранения сессии:**
  - Исправлена ложная фильтрация валидных токенов при авторизации: Nuxt 3 первоначально сохраняет куку с пустым профилем пользователя (`user: null`), из-за чего кука ошибочно считалась невалидной и удалялась.
  - Добавлена автоматическая подгрузка никнейма, аватара и баланса пользователя через API `https://api.mannco.store/user/infos` при первичном входе, если в токене профиль ещё не был заполнен.
  - Устранена ошибка склеивания параметров кук без точки с запятой (`...ydgauth=...`), блокировавшая повторный запуск бота.
  - Реализовано безопасное обновление кук через массив значений и автоматическое расклеивание повреждённых строк.

- ⚙️ **Стабильность сборки и модулей:**
  - Корректная семантическая версия `2.3.1` в `package.json` для совместимости со сборщиком `electron-builder`.
  - Добавлена обработка ошибок сборки (`process.exit(1)`).
  - Добавлена защита от отсутствия пути пользовательских данных в `json-storage.js`, предотвращающая ошибки при сохранении настроек.
